# 维护说明

## 源码位置

| 文件 | 职责 |
| --- | --- |
| `src/LightCapture.cpp` | 入口、全局快捷键、托盘、截图、保存窗口临时进程 |
| `src/ClipboardHistory.h` | 剪贴板监听、文字/图片页签、预览与设置 |
| `src/ClipboardStore.h` | Windows SQLite 动态加载、历史存储、去重和容量清理 |
| `src/Startup.h` | 当前用户的 Windows 登录任务及旧自启项迁移 |
| `src/app.rc` | 图标和文件版本 |
| `scripts/build.cmd` | 发现 Visual Studio，编译程序和测试 |
| `scripts/test.ps1` | 使用独立临时数据运行原生测试 |

首次整理仓库时保留了已运行版本的文件划分。后续可以把较大的头文件拆分成 `.h/.cpp`；拆分前先保证测试通过，避免同时改结构和功能。

## 自动测试

```powershell
.\scripts\build.cmd
.\scripts\test.ps1
```

覆盖范围：

- 截图区域裁剪、DIB 像素和 PNG 编解码。
- 重复创建与释放图像的 GDI 对象数。
- 中文与 emoji、全文搜索、去重、分类、收藏和 SQLite 重开保留。
- 容量淘汰、收藏保护，实际加入 510 条后保留 500 条。
- PNG 导出、原子覆盖、尺寸和像素，以及空内容和错误路径。

测试数据全部写到 `build/test-results-*`。原生测试不修改用户剪贴板、不注册登录任务、不触发物理快捷键。`--self-test` 会创建一个隐藏的消息测试窗口，仍需要 Windows 图形子系统。

## 真实桌面检查

自动测试不能代替这些操作：

1. 复制一段普通文字，检查文字页；复制图片，检查图片页和缩略图比例。
2. 两页分别搜索、勾选收藏、切换，再退出重开；检查历史、页签和筛选是否保留。
3. 复制历史到记事本或图片编辑器；测试 PNG 保存和取消。
4. Alt+A 框选、反向拖动、复制、保存和取消；双显示器与混合缩放需要另测。
5. 开启与关闭自启；确认登录任务路径、延迟、电池供电和运行时限。实际登录触发需要真实登录验证。
6. 反复打开关闭图片页，检查内存和 GDI 对象是否持续增长。

只用生成的测试文字和图片。不要把真实剪贴板数据库、私人截图或包含个人目录的日志加进仓库。

## 更新正在使用的程序

构建和测试使用 `build/`，不要直接覆盖运行中的 EXE。更新时先从托盘退出，保留用户数据库，再替换部署目录内的 EXE。

如果程序位置改变，需要从新位置重新开启自启，并更新桌面快捷方式。程序参数 `--clipboard` 可以直接打开历史。

## 发版检查

1. 修改 `src/app.rc` 版本号和 `CHANGELOG.md`。
2. 本地构建、原生测试和相关桌面检查通过。
3. 推送分支，检查 GitHub Actions 结果，再合入 `main`。
4. 将经过验证的 EXE 作为 Release 附件发布；不要提交数据库、日志或测试文件。

默认 CI 只有仓库读取权限，不会自动发布 Release 或变更运行中的软件。
